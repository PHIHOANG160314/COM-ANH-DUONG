# Tech Stack - Cơm Ánh Dương React App

## Frontend Core

- **Framework**: React 19
  - Latest features: automatic batching, transitions, concurrent rendering
  - Enhanced Suspense and Error Boundaries

- **Language**: TypeScript 5.x
  - Strict type checking
  - Enhanced developer experience with IntelliSense

- **Build Tool**: Vite 6.x
  - Fast HMR (Hot Module Replacement)
  - Optimized production builds
  - Native ESM support

## UI & Styling

- **UI Library**: Material UI v6 (MUI)
  - Material Design 3 components
  - Responsive design system
  - Customizable theming

- **Design System**: Material Design 3
  - Dynamic color schemes
  - Accessibility-first components
  - Mobile-optimized interactions

## Routing & Navigation

- **Router**: React Router v6
  - File-based routing structure
  - Nested routes for layouts
  - Protected routes for authentication

## Backend & Data

- **BaaS**: Supabase
  - PostgreSQL database
  - Row-level security (RLS)
  - Real-time subscriptions
  - Authentication & authorization
  - Storage for media files

- **State Management**:
  - React hooks (useState, useReducer)
  - Context API for global state
  - Supabase client for server state

## Forms & Validation

- **Forms**: React Hook Form
  - Performant form handling
  - Built-in validation
  - TypeScript support

- **Validation**: Zod
  - Schema-based validation
  - Type inference
  - Runtime type checking

## PWA & Offline

- **PWA**: Vite PWA Plugin
  - Service Worker generation
  - Offline support
  - App installation
  - Push notifications

## Development Tools

- **Linting**: ESLint
  - React-specific rules
  - TypeScript integration

- **Type Checking**: TypeScript compiler
  - Strict mode enabled
  - Path aliases configured

- **Package Manager**: npm
  - Lock file for dependency consistency
