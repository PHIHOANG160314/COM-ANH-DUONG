## 13. CODE MANAGEMENT

### Code Format Rules
- Use UPPERCASE only
- Keep it short (max 10 chars)
- Easy to remember
- No confusing characters (0/O, 1/I)

### Code Distribution Channels
1. **Facebook posts** - Public codes
2. **Zalo broadcast** - Subscriber exclusives
3. **SMS** - Personal codes (birthday, loyalty)
4. **Website banner** - Current active codes
5. **Flyers** - First-timer codes

### Code Tracking
Track these metrics weekly:
- Usage count per code
- Revenue per code
