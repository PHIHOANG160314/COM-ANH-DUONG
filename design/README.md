# Cơm Ánh Dương - UI Design Files

Thư mục này chứa các file thiết kế UI sử dụng Pencil extension.

## Files

| File | Mô tả |
|------|-------|
| `customer.pen` | Giao diện đặt món khách hàng |
| `admin.pen` | Dashboard quản lý |
| `kitchen.pen` | Màn hình bếp |
| `staff.pen` | Giao diện nhân viên |
| `shipper.pen` | App giao hàng |

## Hướng dẫn sử dụng

1. Mở file `.pen` trong VS Code với Pencil extension
2. Sử dụng AI prompts để tạo/chỉnh sửa design
3. Export HTML/CSS khi hoàn thành
