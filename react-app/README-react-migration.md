# Cơm Ánh Dương - React 19 Application

Modern React 19 + TypeScript + Vite application for Com Anh Duong restaurant management system.

## Tech Stack

- **Framework:** React 19
- **Language:** TypeScript 5.7+
- **Build Tool:** Vite 7.x
- **UI Components:** @material/web (Material Design 3)
- **Routing:** React Router DOM v7
- **State Management:** Zustand
- **Server State:** TanStack Query
- **Backend:** Supabase
- **i18n:** i18next

## Routes

- `/` - Landing page
- `/customer` - Customer ordering
- `/kitchen` - Kitchen Display System
- `/shipper` - Shipper delivery
- `/staff-mobile` - Staff POS

## Getting Started

```bash
npm install
cp .env.example .env
# Configure VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev
```

## Build

```bash
npm run build  # Production build
npm run preview  # Preview build
```
