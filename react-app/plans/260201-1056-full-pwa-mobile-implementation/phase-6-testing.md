# Phase 6: Testing & Validation

## Context
Rigorous testing to ensure compliance with PWA standards and user expectations.

## Implementation Steps

1.  **Lighthouse Audit**
    - Run Lighthouse > Progressive Web App.
    - Fix any issues to reach score 90-100.
    - Common fixes: `apple-touch-icon`, `viewport`, `service-worker`, `offline` status.

2.  **Real Device Testing**
    - **iOS**: Use iPhone. Open in Safari. Tap Share. Verify "Add to Home Screen" has icon. Launch app. Check splash screen. Check status bar.
    - **Android**: Use Android phone. Open Chrome. Check for Install Prompt (Banner/Bottom sheet). Install. Check App Drawer icon. Launch.
