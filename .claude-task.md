# Task: Kiểm tra toàn diện API dự án Cơm Ánh Dương

## Mục tiêu
Kiểm tra trạng thái hoạt động của các API endpoints quan trọng sau khi đã sửa lỗi Database Schema.

## Các bước thực hiện

1. **Kiểm tra kết nối Supabase**:
   - Verify environment variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)

2. **Test các bảng quan trọng (Read Operation)**:
   - Query bảng `orders` (kiểm tra cột mới `delivery_address`, `customer_name`)
   - Query bảng `order_items` (kiểm tra quan hệ với `orders`)
   - Query bảng `profiles` (kiểm tra bảng mới tạo)
   - Query bảng `menu_items`

3. **Validate Relationships**:
   - Kiểm tra Foreign Key giữa `orders` và `profiles` (nếu có data)
   - Kiểm tra Foreign Key giữa `order_items` và `orders`

4. **Báo cáo kết quả**:
   - Liệt kê các endpoint hoạt động tốt (200 OK)
   - Liệt kê các endpoint lỗi (nếu có)
   - Xác nhận hệ thống đã sẵn sàng cho Admin/Kitchen app chưa.
